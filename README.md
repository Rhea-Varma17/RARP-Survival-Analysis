# RARP-Survival-Analysis
Survival analysis and PSA threshold assessment following Robot-Assisted Radical Prostatectomy (RARP) using Kaplan–Meier and ROC–AUC methods.


## Project Overview
This project focuses on **survival analysis** and **PSA threshold assessment** following **Robot-Assisted Radical Prostatectomy (RARP)**. Using Python, it applies **Kaplan–Meier survival curves** and **ROC–AUC methods** to evaluate post-operative outcomes and biochemical recurrence.

> **Note:** Due to patient confidentiality, the raw dataset is not included in this repository.

---

## Notebooks

1. **01_RARP_Exploratory_Data_Analysis.ipynb**  
   - Performs initial data exploration  
   - Summarizes clinical variables and PSA follow-up  
   - Prepares data for survival analysis

2. **02_RARP_Survival_Analysis_PSA_AUC.ipynb**  
   - Conducts Kaplan–Meier survival analysis  
   - Calculates hazard ratios using Cox Proportional Hazards  
   - Assesses PSA thresholds with ROC–AUC metrics  
   - Visualizes outcomes using plots saved in `figures/`
