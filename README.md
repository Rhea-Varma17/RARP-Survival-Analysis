# RARP-Survival-Analysis
Survival analysis and PSA threshold assessment following Robot-Assisted Radical Prostatectomy (RARP) using Kaplan–Meier and ROC–AUC methods.


## Project Overview
This project focuses on **survival analysis** and **PSA threshold assessment** following **Robot-Assisted Radical Prostatectomy (RARP)**. Using Python, it applies **Kaplan–Meier survival curves** and **ROC–AUC methods** to evaluate post-operative outcomes and biochemical recurrence.

> **Note:** Due to patient confidentiality, the raw dataset is not included in this repository.

---

## Key Questions Addressed
- How does **time to biochemical recurrence** evolve following RARP?
- Are specific **PSA thresholds** associated with increased recurrence risk?
- How well does post-operative PSA discriminate recurrence outcomes?

## Notebooks

   - Prepares data for survival analysis

2. **02_RARP_Survival_Analysis_PSA_AUC.ipynb**  
   - Conducts Kaplan–Meier survival analysis  
   - Calculates hazard ratios using Cox Proportional Hazards  
   - Assesses PSA thresholds with ROC–AUC metrics  
   - Visualizes outcomes using plots saved in `figures/`

## Methods Summary
The analysis is conducted using established statistical techniques commonly applied in clinical research:

- **Kaplan–Meier survival analysis**  
  To estimate recurrence-free survival over time
- **Cox Proportional Hazards modeling**  
  To quantify relative risk (hazard ratios) associated with PSA and clinical covariates
- **ROC–AUC analysis**  
  To evaluate the discriminative ability of PSA thresholds for recurrence

All modeling choices prioritize **interpretability and clinical relevance** over predictive complexity.

## Dataset Schema (Conceptual)
The analysis assumes a structured clinical dataset with variables similar to:

- `time_to_event` — Follow-up time (months)
- `event` — Recurrence indicator (1 = recurrence, 0 = censored)
- `psa_postop` — Post-operative PSA value
- `age` — Patient age at surgery
- `gleason_score` — Tumor grade
- `pathological_stage` — Disease stage

*(Exact variable names may differ depending on data source.)*
